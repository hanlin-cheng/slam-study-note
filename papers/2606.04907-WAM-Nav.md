## 1. 论文核心观点与主张的系统梳理 {#1}

### 1.1 研究背景与动机 {#11}

论文针对 embodied visual navigation 的核心矛盾展开：机器人需要在复杂、未知、障碍密集环境中生成平滑、无碰撞、可执行轨迹，但主流学习式方法仍存在明显分裂。

第一类是 reactive end-to-end policy，例如 GNM、ViNT、NoMaD、NavDP 等。它们直接从视觉观测到动作，推理快、部署简单，但缺少对未来观测后果的显式建模。论文认为这种即时反应式策略容易在 cluttered environments 中陷入局部最优、靠近障碍后才急转，导致轨迹抖动或碰撞。

第二类是 world-model / visual imagination 方法，例如 Pathdreamer、Navigation World Models、NavigateDiff 等。它们提供前瞻能力，但常把未来视觉预测和动作决策拆成两个模块：先生成未来图像或视觉子目标，再用 inverse dynamics 或额外策略执行。作者指出这种解耦会带来两个问题：视觉预测误差在多步 rollout 中累积，且多模块推理延迟较高。

第三个问题是目标类型不统一。很多导航策略只适配 Image-Goal、Point-Goal 或 No-Goal 中的一类；即使 NavDP 支持多任务，作者认为其 unimodal alignment 会造成不同任务性能不均衡。因此 WAM-Nav 的动机是同时解决“前瞻性、实时性、轨迹平滑性、多目标统一”四个工程瓶颈。

![Figure 1 WAM-Nav 范式对比](../media/papers/2606.04907-WAM-Nav/f25b60164d-figure_01.png)

Figure 1 对比了 reactive mapping、modular decoupling 和 WAM-Nav 的 joint modeling。图中最关键的信息是：WAM-Nav 不把 future observation 当成单独模块的长序列输出，而是在策略内部以 latent future 形式与 action trajectory 共同生成；下方柱状图则对应三类任务上的整体性能优势。

### 1.2 问题设定 {#12}

论文研究的是 mapless visual navigation，目标形式包括 Image-Goal <span class="paper-math">\(g^{\mathrm{img}}\)</span>、Point-Goal <span class="paper-math">\(g^{\mathrm{pt}}\)</span> 和 No-Goal exploration <span class="paper-math">\(g^{\varnothing}\)</span>。在时刻 <span class="paper-math">\(t\)</span>，agent 接收历史视觉观测 <span class="paper-math">\(\mathcal{O}_t=\{o_{t-k+1},\ldots,o_t\}\)</span>、动作累积得到的 ego-motion 历史 <span class="paper-math">\(\mathcal{S}_t=\{s_{t-k+1},\ldots,s_t\}\)</span>，以及目标条件 <span class="paper-math">\(g\)</span>。

附录中的问题定义把策略写成条件联合生成：



<div class="paper-math">\[p_\theta(\mathbf{A}_t,\mathbf{Z}_{t+1:t+H_{\mathrm{vis}}}\mid C)\]</div>



这条公式负责定义 WAM-Nav 的核心任务：给定上下文 <span class="paper-math">\(C\)</span>，同时预测未来动作轨迹 <span class="paper-math">\(\mathbf{A}_t=\{a_t,\ldots,a_{t+H_{\mathrm{act}}-1}\}\)</span> 和短时域潜在视觉前瞻 <span class="paper-math">\(\mathbf{Z}_{t+1:t+H_{\mathrm{vis}}}=\{z_{t+1},\ldots,z_{t+H_{\mathrm{vis}}}\}\)</span>。自然语言直译是：机器人一边规划接下来怎么走，一边在 latent space 里估计短期未来会看到什么。工程上，<span class="paper-math">\(C\)</span> 是由视觉历史、运动历史和目标编码融合得到的 Transformer conditioning tokens。

### 1.3 核心观点（Claims）的逐条梳理 {#13-claims}

Claim 1：联合建模 action generation 和 latent visual foresight 比 reactive policy 更适合复杂导航。对应位置是 Introduction、Asymmetric Action-Foresight Generation 和 Image-Goal 主结果。实验中 WAM-Nav 在 Image-Goal 平均 SR 为 50.2%，NavDP 为 43.4%，提升 6.8 个百分点；相对更弱的 GNM、ViNT、NoMaD、NWM 差距更大。

Claim 2：不应采用长时域视觉 rollout，而应采用长时域动作 + 短时域视觉前瞻的不对称设计。对应位置是 Method 3.3 和 visual horizon ablation。作者的证据是固定 <span class="paper-math">\(H_{\mathrm{act}}=24\)</span> 时，<span class="paper-math">\(H_{\mathrm{vis}}=1\)</span> 的 SR/SPL 为 50.2/48.2，扩展到 4、8、24 后持续下降。

Claim 3：Dual-Stream Contextual Conditioning 同时需要视觉记忆和运动历史。对应位置是 Method 3.2 和 component ablation。消融显示 latent prediction alone 从 42.1% SR 提升到 45.7%，motion trajectory alone 为 43.9%，两者结合达到 50.2%。

Claim 4：Unified Goal Alignment 能让单一策略支持 Image-Goal、Point-Goal 和 No-Goal，而不是为每种任务重训。对应位置是 Method 3.1、主结果表和 goal alignment ablation。证据是 WAM-Nav 在三类任务平均值上均优于或接近强基线，并且 <span class="paper-math">\(g_V+g_G\)</span> 在 No-Goal 上最好、在 Image/Point 之间取得较平衡性能。

Claim 5：WAM-Nav 能保持实时效率并实现真实机器人零样本部署。对应位置是 efficiency table、real-world deployment 和硬件附录。论文报告 WAM-Nav 推理延迟 0.26 s、0.7 TFLOPs，在 Unitree G1 上 1 Hz 推理、50 Hz 控制，四个真实场景平均成功率 85%。

### 1.4 创新性与贡献边界 {#14}

论文的实质创新在三个机制组合：第一，把世界模型前瞻压缩到 latent visual foresight，并与动作轨迹在 shared DiT 内做 joint diffusion；第二，用 asymmetric horizon 约束未来视觉只预测短期，避免导航中大视角变化带来的长 rollout 误差；第三，用 <span class="paper-math">\(g_V\)</span> 和 <span class="paper-math">\(g_G\)</span> 分流保留目标的视觉语义与几何导向信息。

边界也需要明确。WAM-Nav 没有提出新的 flow matching 理论、DiT 基础结构或 DINOv2/Stable Diffusion VAE 预训练方法；它使用这些成熟组件构造导航策略。它也没有从理论上证明 latent foresight 必然降低碰撞率，主要依赖实验对比和消融证明机制有效。

## 2. 关键论据、理论基础与数学方法的深度解析 {#2}

### 2.1 理论基础与学术渊源 {#21}

论文建立在五类工作之上。第一是传统 SLAM / mapping-and-planning，如 ORB-SLAM3、RTAB-Map 和 Active Neural SLAM，它们代表显式建图路线。第二是 end-to-end visual navigation，包括 GNM、ViNT、NoMaD、NavDP、iPlanner、ViPlanner、DD-PPO 等，它们是主实验基线。第三是 world model / visual imagination，如 Pathdreamer、Navigation World Models、NavigateDiff、WMNav 和 RAE-NWM，这些工作为“未来视觉预测辅助导航”提供背景。第四是生成式策略学习，包括 diffusion policy、flow matching 和 Streaming Flow Policy。第五是视觉表征和潜空间压缩，包括 DINOv2 和 Stable Diffusion VAE。

WAM-Nav 对这些理论的继承是工程性的：用 DINOv2 编码视觉 patch；用 VAE latent 表示未来视觉；用 flow matching 训练从噪声到动作/视觉 latent 的速度场；用 InfoNCE 对齐多目标表示。论文没有提出新的定理或收敛证明。

### 2.2 问题形式化与建模选择 {#22}

统一目标对齐首先把异构目标编码成 base embedding，再投影到两个功能空间。式 (1) 为：



<div class="paper-math">\[g_V = \psi_V(e_g), \quad g_G = \psi_G(e_g), \quad \text{with} \quad e_g = E_{\phi}(g)\]</div>



这条公式负责把 Image-Goal、Point-Goal、No-Goal 变成统一接口。<span class="paper-math">\(E_\phi\)</span> 随目标模态变化：image goal 使用从头训练的 ViT，relative coordinate 使用 sinusoidal positional encoding，goal-free exploration 使用 masked zero-state representation。<span class="paper-math">\(g_V\)</span> 用于视觉语义检索，<span class="paper-math">\(g_G\)</span> 用于轨迹几何导向。代码中通常对应三个 encoder 分支和两个 linear projection head。若只保留 <span class="paper-math">\(g_V\)</span>，Image-Goal 更强但 Point-Goal 变弱；若只保留 <span class="paper-math">\(g_G\)</span>，Point-Goal 更强但 Image-Goal 变弱，这与附录 goal alignment 消融一致。

极简例子：若目标是一张终点图像，<span class="paper-math">\(e_g\)</span> 包含“沙发旁门口”的视觉语义，<span class="paper-math">\(g_V\)</span> 应帮助历史视觉 patch 找到相似区域；若目标是相对坐标 <span class="paper-math">\((3,1)\)</span>，<span class="paper-math">\(g_G\)</span> 应更强调“向前 3 米、右侧 1 米”的几何方向。把二者混成单一 token 容易让某一类目标主导训练。

### 2.3 核心推导与算法构造 {#23}

![Figure 2 WAM-Nav 方法总览](../media/papers/2606.04907-WAM-Nav/03b42f81e0-figure_02.png)

Figure 2 展示了 WAM-Nav 的完整流水线：过去观测、三类目标和运动轨迹进入 DSCC；目标被分成 visual semantic 与 trajectory geometric 两类查询；融合后的 context <span class="paper-math">\(C\)</span> 条件化 shared Diffusion Transformer；最后输出 action head 和 latent head。该图支撑论文最核心的系统主张：视觉前瞻不是外置模块，而是动作生成的一部分。

视觉记忆通过目标相关性加权。式 (2) 为：



<div class="paper-math">\[\alpha = \sigma\left(\frac{g_V V^\top}{\sqrt{D}}\right) \in \mathbb{R}^{B\times(k\cdot P)\times1}\]</div>



这里 <span class="paper-math">\(V\)</span> 是由 DINOv2 从历史 RGB 观测得到的 patch memory，<span class="paper-math">\(B\)</span> 是 batch size，<span class="paper-math">\(k\)</span> 是历史窗口长度，<span class="paper-math">\(P\)</span> 是每帧 patch 数，<span class="paper-math">\(D\)</span> 是隐维度。自然语言直译：用视觉目标查询 <span class="paper-math">\(g_V\)</span> 去给历史视觉 patch 打相关性分数。它类似 scaled dot-product attention，但用 sigmoid 得到每个 patch 的独立门控，而不是 softmax 归一化。

式 (3) 用 residual gating 更新视觉记忆：



<div class="paper-math">\[\tilde{V}=V+\alpha\odot V\]</div>



如果某个 patch 与目标高度相关，<span class="paper-math">\(\alpha\)</span> 接近 1，该 patch 特征约变成 <span class="paper-math">\(2V\)</span>；若不相关，<span class="paper-math">\(\alpha\)</span> 接近 0，则保留原特征。极简数值例子：若某 patch 与 <span class="paper-math">\(g_V\)</span> 的缩放点积为 2，<span class="paper-math">\(\sigma(2)\approx0.88\)</span>，更新后强度为 <span class="paper-math">\(1.88V\)</span>；若为 -2，<span class="paper-math">\(\sigma(-2)\approx0.12\)</span>，更新后为 <span class="paper-math">\(1.12V\)</span>。这说明该模块不是删除无关 patch，而是增强相关 patch。

运动历史通过 causal Transformer 编码后，用几何目标查询。式 (4) 为：



<div class="paper-math">\[o_{\mathrm{kin}}=\mathrm{CrossAttn}(g_G,H,H)\in\mathbb{R}^{B\times D}\]</div>



这条公式把过去 <span class="paper-math">\(k\)</span> 步的相对位姿序列压缩成一个目标相关的运动 token。<span class="paper-math">\(H\)</span> 是 motion Transformer 的输出，query 是 <span class="paper-math">\(g_G\)</span>，key/value 都是 <span class="paper-math">\(H\)</span>。工程上，它让模型知道“当前朝向、历史速度趋势和目标方向是否一致”。若删去这一路，论文消融显示只靠视觉前瞻的整体 Image-Goal SR 为 45.7%，不如完整模型 50.2%。

条件融合用 motion token 去偏置 learnable queries。式 (5) 为：



<div class="paper-math">\[C=\mathrm{TransformerDecoder}(Q_c+\phi(o_{\mathrm{kin}}),\tilde{V},\tilde{V})\]</div>



这条公式的作用是构造最终 conditioning context <span class="paper-math">\(C\)</span>。直译是：把运动状态注入查询 token，再去读取目标增强后的视觉记忆。代码中对应 Transformer decoder，其中 query 来自 <span class="paper-math">\(Q_c+\phi(o_{\mathrm{kin}})\)</span>，key/value 来自 <span class="paper-math">\(\tilde{V}\)</span>。这种设计让运动连续性主动约束视觉检索，而不是简单 concat。

Asymmetric Action-Foresight Generation 使用 flow matching。式 (6) 为：



<div class="paper-math">\[\mathbf{A}_{\tau}=(1-\tau)\mathbf{A}_0+\tau\mathbf{A}_1,\quad \mathbf{Z}_{\tau}=(1-\tau)\mathbf{Z}_0+\tau\mathbf{Z}_1\]</div>



其中 <span class="paper-math">\((\mathbf{A}_0,\mathbf{Z}_0)\)</span> 来自标准高斯噪声，<span class="paper-math">\((\mathbf{A}_1,\mathbf{Z}_1)\)</span> 是真实动作轨迹和真实未来视觉 latent，<span class="paper-math">\(\tau\in[0,1]\)</span> 是流时间。自然语言直译：在噪声和真实数据之间做线性插值，让网络学习“应该往哪个方向流向真实样本”。这与传统 denoising diffusion 的噪声预测形式不同，训练目标是速度场。

式 (7) 定义 shared DiT 的速度预测：



<div class="paper-math">\[\hat{u}_A,\hat{u}_Z=f_\theta(\mathbf{A}_{\tau},\mathbf{Z}_{\tau},\tau,C)\]</div>



这里 <span class="paper-math">\(\hat{u}_A\)</span> 是动作速度场预测，<span class="paper-math">\(\hat{u}_Z\)</span> 是视觉 latent 速度场预测。共享 DiT 让 action tokens 和 latent visual tokens 在 self-attention 中交互，使视觉前瞻成为动作生成的约束。若改成 decoupled DiT，附录消融中 SR/SPL 为 45.9/44.6；fully shared DiT 为 50.2/48.2。

![Figure 5 shared DiT block](../media/papers/2606.04907-WAM-Nav/1d75c78a5c-figure_05.png)

Figure 5 展示了 shared DiT block：action tokens 与 latent foresight tokens 分别通过 adaLN 分支调制，但共享 self-attention、cross-attention 和 FFN。这个结构解释了“asymmetric”不是两个完全独立模块，而是在共享参数中处理不同 horizon 和不同 token 类型。

训练目标见式 (8)：



<div class="paper-math">\[\mathcal{L}_{\mathrm{total}}=\mathbb{E}_{\tau,\mathbf{A}_0,\mathbf{Z}_0}\left[\|\hat{u}_A-u_A\|_2^2+\lambda_{\mathrm{img}}\|\hat{u}_Z-u_Z\|_2^2\right]+\lambda_{\mathrm{align}}\mathcal{L}_{\mathrm{align}}\]</div>



这条公式同时优化三件事：动作速度场回归、视觉 latent 速度场回归、多目标对齐。<span class="paper-math">\(\lambda_{\mathrm{img}}=0.25\)</span>，<span class="paper-math">\(\lambda_{\mathrm{align}}=0.1\)</span> 来自附录超参数表。工程上，第一项对应 action head 的 MSE，第二项对应 latent head 的 MSE，第三项是 symmetric contrastive InfoNCE。若 <span class="paper-math">\(\lambda_{\mathrm{img}}\)</span> 太大，模型可能过度拟合视觉预测；若太小，latent foresight 对动作的正则作用不足。论文没有给出 loss weight 敏感性。

### 2.4 理论结论的适用范围 {#24}

WAM-Nav 的理论适用范围是：视觉历史和运动历史可观测、训练数据覆盖足够多的室内导航动态、目标模态可被 <span class="paper-math">\(E_\phi\)</span> 编码、短时域视觉 latent 足以约束局部几何。它没有证明 flow matching 训练出的联合分布一定能提高安全性，也没有证明 <span class="paper-math">\(H_{\mathrm{vis}}=1\)</span> 在所有平台上最优。

论文中最强的理论假设是 latent visual foresight 能作为 action generation 的 perception-grounded regularizer。实验支持这一点，但这仍是经验命题。真实环境中，如果 DINOv2 特征对透明玻璃、低矮障碍、强反光、动态行人不稳，latent foresight 可能不能提供可靠约束。

## 3. 实验设计与实验结果的充分性分析 {#3}

### 3.1 实验目标与论文主张的对应关系 {#31}

论文围绕五个研究问题组织实验。Q1 检验三类任务的零样本泛化与平衡性；Q2 检验 cluttered environment 中前瞻避障机制；Q3 检验推理效率；Q4 检验组件贡献；Q5 检验真实机器人 sim-to-real。

训练数据是 VLN-N1，包含 Replica、Matterport3D、Gibson、3D-FRONT、HSSD、HM3D 等六类 3D scene assets，经过 domain randomization 生成超过 400 小时、200K+ collision-free smooth first-person navigation trajectories。评估在 IsaacSim 中使用 ClearPath Dingo，场景为 ClutterScenes 和 InternScenes，共 60 个场景类型组合、每场景 100 episode，总计 6000 episodes。所有方法使用原始 pretrained weights，不额外 finetune。

评价指标与任务对应：Image-Goal / Point-Goal 使用 SR 和 SPL；No-Goal 使用 explored Area 和 episode Time，120 秒封顶，局部卡住提前终止。指标能反映任务完成、效率和探索覆盖，但不能完整衡量碰撞严重程度、身体可通过性、能耗、动态避障和控制稳定性。

### 3.2 实验设置合理性 {#32}

基线覆盖较广。Image-Goal 对比 GNM、ViNT、NoMaD、NWM、NavDP；Point-Goal 对比 DD-PPO、iPlanner、ViPlanner、NavDP；No-Goal 对比 GNM、ViNT、NoMaD、NavDP。这个设置能覆盖 RL、reactive foundation navigation、diffusion policy、world model 和 local planner。

不足是：论文没有明确说明每个 baseline 是否在完全相同传感器输入、动作频率、碰撞终止规则和控制器设置下运行；尤其 NWM 和 WAM-Nav 都涉及未来视觉预测，但一个是 modular world model，一个是 latent joint model，公平对比需要清楚说明 rollout budget、candidate 数和推理步数。附录给出 baseline 描述，但主文没有足够细节。

## 4. 与当前领域主流共识及反对观点的关系 {#4}

### 4.1 与主流观点的一致性 {#41}

WAM-Nav 延续了视觉导航领域从显式建图到学习式策略、再到 foundation / diffusion / world model 的趋势。GNM 和 ViNT 证明大规模异构导航数据可形成通用视觉导航 prior；NoMaD 和 NavDP 证明 diffusion policy 能生成多模态轨迹并支持 sim-to-real；NWM、Pathdreamer、NavigateDiff 证明 future visual prediction 对导航前瞻有价值；WAM-Nav 则接受这些共识，并把视觉预测从外置模块压缩进 shared latent joint generation。

它也与 flow matching / diffusion policy 的主流方向一致：不直接回归单条动作，而是建模动作轨迹分布。论文中的 straight-line probability path 和 velocity regression 与 Flow Matching for Generative Modeling、Streaming Flow Policy 的思想一致。

### 4.2 与反对或竞争观点的分歧 {#42}

与 reactive policy 的分歧：WAM-Nav 认为直接从当前/历史观测到动作缺乏 predictive reasoning，因此在 clutter 中反应滞后。NavDP 作为最强 reactive/diffusion baseline，在 Image-Goal 上仍落后 6.8 个 SR 点，是论文支撑该分歧的主要证据。

与 modular world model 的分歧：NWM 等方法通过未来视觉 rollout 评估或辅助规划，但 WAM-Nav 认为解耦结构增加延迟和误差累积。效率表中 NWM 延迟 1.43 s、8.3 TFLOPs，WAM-Nav 为 0.26 s、0.7 TFLOPs，支持“latent short-horizon joint foresight 更高效”的观点。

与长时域视觉预测的分歧：论文通过 <span class="paper-math">\(H_{\mathrm{vis}}\)</span> 消融明确反驳“预测越长越好”。当 <span class="paper-math">\(H_{\mathrm{vis}}\)</span> 从 1 增至 24，SR 从 50.2 降到 30.4，说明在导航中长视觉 rollout 可能因大视角变化积累误差。

### 4.3 论文在学术版图中的定位 {#43}

WAM-Nav 是 world-action model 思路在视觉导航中的定制化落地。它不像传统 SLAM 那样追求显式地图可靠性，也不是纯 foundation reactive policy；它处于“生成式策略 + 潜在世界模型 + 多目标统一导航”的交叉位置。更准确地说，它是对 NavDP / NWM / NavigateDiff 的机制级改进，而不是完全平行替代路径。

## 5. 对论文理论体系的严肃反驳与系统性质疑 {#5}

### 5.1 核心假设层面的质疑 {#51}

第一，论文假设短时域 latent foresight 足以约束动作安全，但 latent space 中的几何约束是否总能对应真实碰撞风险并不清楚。失败案例已经显示：低矮障碍和侧向障碍可能在相机视角中弱化，latent foresight 也会继承这种感知盲区。

第二，论文假设统一目标对齐能平衡三类任务，但 goal alignment 消融显示 only <span class="paper-math">\(g_V\)</span> 在 Image-Goal 上反而高于完整模型，only <span class="paper-math">\(g_G\)</span> 在 Point-Goal 上也高于完整模型。完整模型的价值是均衡多任务，而不是每个单任务最优。这个边界需要在结论中更清楚地区分。

第三，论文假设从 Dingo 仿真到 G1/H2 humanoid 的跨本体迁移可通过视觉-动作 prior 自然实现，但真实失败案例恰恰说明 embodiment geometry 未建模会造成身体碰撞。跨本体实验支持“有一定泛化”，不支持“本体无关安全”。

### 5.2 数学推导与理论主张的边界 {#52}

论文的数学部分主要是建模定义和损失函数，而不是可验证理论。式 (1) 到式 (8) 说明如何构建模型，但没有证明 shared DiT 一定优于 decoupled DiT，也没有推导 <span class="paper-math">\(H_{\mathrm{vis}}=1\)</span> 的最优性。visual horizon 的结论来自经验消融。

InfoNCE alignment 被描述为最大化 equivalent objectives 的 mutual information，但论文未给出正负样本构造细节、batch 内负样本是否足够、不同目标模态是否存在 shortcut。若对齐损失主要学到数据集偏差，可能并不能泛化到新的目标表达。

### 5.3 工程实现与实际适用性 {#53}

WAM-Nav 真实部署使用 Unitree G1、RealSense D455、RTX 4060、1 Hz 模型推理和 50 Hz MPC 控制。这个链路可运行，但 1 Hz 对动态人群和快速变化障碍可能不足。论文的真实场景包括 meeting room、warehouse、lobby、parking lot，但每个场景只有 10 trials，且没有系统报告动态障碍、多人干扰、照明变化、湿滑地面、透明障碍、镜面反射等条件。

另外，模型训练成本约 <span class="paper-math">\(8\times120\)</span> GPU hours，虽然可接受，但并不轻量。它依赖 VLN-N1 大规模仿真轨迹、DINOv2、Stable Diffusion VAE、DiT 和 MPC 控制器；开源数据、训练细节和部署栈的完整性会显著影响复现难度。

### 5.4 整体理论体系的稳健性 {#54}

整体上，WAM-Nav 的机制链条是合理的：目标分流解决多任务表达，DSCC 解决视觉与运动上下文融合，shared DiT 让动作与 latent foresight 相互约束，asymmetric horizon 控制视觉 rollout 误差。实验也基本覆盖主张。

但它的稳健性仍是经验性的。一个更简单的替代解释是：提升主要来自“更强的上下文编码 + 合适的历史窗口 + 更多训练数据/结构容量”，而 latent foresight 本身只是额外正则。虽然消融显示 latent prediction 有贡献，但没有给出预测质量与碰撞减少之间的定量相关性，也没有把 latent head 移除但保持参数量相近的严格控制实验。

## 6. 最终结论 {#6}

### 6.1 论文价值总结 {#61}

WAM-Nav 是一篇机制完整、实验覆盖较广的视觉导航论文。它抓住了当前导航 world model 的关键痛点：长视觉 rollout 慢且容易错，reactive policy 又缺少前瞻。论文提出的 asymmetric latent world-action modeling 是一个务实折中，用短期潜在视觉预测约束长期动作生成，同时保持接近实时的推理效率。

### 6.2 一句话总评 {#62}

WAM-Nav 在 Image-Goal 和跨任务统一导航上有明确实证价值，但其理论保证较弱，真实部署规模仍小，且本体几何和近场感知问题尚未解决。

### 6.3 综合评分（10 分制） {#63-10}

- 创新性：8.0
- 技术严谨性：7.5
- 实验说服力：8.0
- 工程价值：7.5
- 总体评分：7.8

### 6.4 最关键的三条优点 {#64}

1. 机制设计清楚：用 shared DiT 联合建模动作与 latent foresight，避免完全解耦的世界模型规划。
2. 实验覆盖较全：三任务、两大仿真 benchmark、效率、组件消融、visual horizon、跨本体和真实部署都有结果。
3. 不对称 horizon 证据强：<span class="paper-math">\(H_{\mathrm{vis}}=1\)</span> 明显优于长视觉 horizon，直接支撑论文核心设计。

### 6.5 最关键的三条问题 {#65}

1. 理论证明不足：核心结论主要来自经验消融，没有安全性、收敛性或最优 horizon 的理论解释。
2. 真实实验规模有限：四个场景、每场景 10 trials，只能说明初步 sim-to-real 可行性。
3. 本体与近场感知未建模：失败案例表明相机可过不等于身体可过，低矮障碍和侧向障碍仍是关键风险。
